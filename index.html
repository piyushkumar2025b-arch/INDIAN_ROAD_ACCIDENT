DBMS Architecture & Hotspot Scoring Specification

1. Relational Database Normalization

The system strictly adheres to 3rd Normal Form (3NF). Data is decomposed across 9 normalized relations: states, districts, road_types, accident_types, accident_causes, weather_conditions, locations, accidents, and profiles. Zero redundant spatial coordinates or text taxonomies are repeated within transactional accident records.

2. Calculated Accident Hotspot Score Formula

Score = min(100, round(
  (Total_Accidents * 2.5) +
  (Fatal_Accidents * 6.0) +
  (Total_Deaths * 7.0) +
  (Total_Injuries * 2.0) +
  (Recency_Weight * 3.0)
))

3. Row Level Security (RLS) & Server-Side Triggers

All DDL relations enforce PostgreSQL Row Level Security. Public sessions possess anonymous read-only access. Administrative mutations (INSERT, UPDATE, DELETE) are guarded by security definer function is_admin(). Accident month and year are derived automatically on database insertion via trigger trg_derive_accident_month_year.

Official Indian Accident Data Sources

This DBMS project integrates accident records, black spot engineering surveys, and casualty reports strictly citing authoritative Indian government sources and open geospatial platforms:

1. data.gov.in — Government of India Open Data Visit Portal ↗

National Open Government Data (OGD) platform providing machine-readable datasets and API endpoints for transport statistics, road safety indicators, and state-wise casualty data.

2. MoRTH — Ministry of Road Transport & Highways Visit Portal ↗

Authoritative annual "Road Accidents in India" reports and National Highways Authority of India (NHAI) Highway Black Spot Identification studies documenting corridor-level fatal crash locations.

3. NCRB — National Crime Records Bureau Visit Portal ↗

Annual "Accidental Deaths & Suicides in India" (ADSI) compendiums detailing road traffic accidents, vehicle types involved, urban area analyses, and long-term historical trends.

4. OpenStreetMap & Nominatim Geocoding OpenStreetMap ↗

Open community-driven spatial cartography and Nominatim forward/reverse geocoding API for resolving Indian highway numbers, milestones, and town boundaries into precise WGS84 coordinates.

5. Hugging Face Open Safety Datasets Hugging Face Hub ↗

Curated public datasets covering Indian vehicular traffic safety, black spot geographic records, and road condition classification models accessible via the open Datasets Hub API.

6. Google Maps Platform & Real-Time Traffic Layer API Key Configured

Google Maps JavaScript API integration featuring dynamic vector dark styling, high-resolution satellite imagery, highway coordinate positioning, and real-time live traffic congestion layer across Indian national corridors.
